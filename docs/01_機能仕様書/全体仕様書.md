# BookShelf 全体仕様書

実装されたアプリの全体像を1枚で見渡すための文書。画面・ルート・テーブル・権限・定期実行の**一覧**だけを載せ、機能ごとの動き（遷移先・文言・入力ルール）は機能仕様書に、決めた理由は技術決定書に書く。

- 記述の基準: 実装コード（コミット `4fe0e82`。発注書95の修正を含む）。記述と実装が食い違った場合は実装が正
- 出典: 各項目の `ファイル:行` はリポジトリ内のパス

## 1. アプリの概要

書籍を登録・共有し、レビュー・お気に入り・いいねで評価を集める読書管理アプリ。応用機能として、書籍の検索と並び替え、ISBNからの書誌情報の自動入力、読書計画と期日の通知、自分のレビューをもとにした読書レポート、トークン認証つきの公開APIを持つ。

### 利用者の区分

| 区分 | できること | 判定の出典 |
|---|---|---|
| ゲスト（未ログイン） | 書籍一覧・書籍詳細・ランキングの閲覧、公開APIの参照系（一覧・詳細）、会員登録・ログイン | `routes/web.php` の auth ミドルウェアの外にあるルート |
| ログインユーザー | 上記に加え、書籍の登録、レビュー投稿、お気に入り・いいね、ジャンルの登録・編集・削除、読書計画、通知、レポート | `app/Http/Middleware/Authenticate.php` |
| 所有者 | 自分が登録した書籍の編集・削除・復元、自分のレビューの編集・削除、自分の読書計画の編集・読了・削除、自分宛て通知の既読化 | 5章の権限一覧 |
| APIトークン保持者 | 公開APIの書き込み系（登録・更新・削除） | `routes/api.php:23` `auth:sanctum` |
