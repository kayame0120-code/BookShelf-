## 1. 前提

着手の前に、次が存在することを現物で確かめる。

| 前提 | 確かめる対象 |
|---|---|
| `reviews` テーブル（`book_id`・`rating`）がある | `SHOW CREATE TABLE reviews`（テーブルの構造は 11 データの担当） |
| `App\Models\Book` が `SoftDeletes` を使っている | 01 書籍の担当 |

| `routes/web.php` | 2章の1本の行 |

## 4. 作るもの

`App\Http\Controllers\RankingController@index`

| 項目 | 確定値 |
|---|---|
| 対象 | レビューが1件以上ある書籍。削除済みの書籍を除く。レビューが0件の書籍は載せない |
| 並び | レビューの評価の平均の高い順。同点は書籍IDの小さい順 |
| 件数 | 上位10件 |

画面（`resources/views/ranking/index.blade.php` の表示内容）

| 項目 | 表示 |
|---|---|
| 見出し | 「評価ランキング TOP 10」 |
| 各書籍 | 順位、画像（無ければ「No Image」）、★、平均評価（小数2桁と小数1桁の2か所）、「(N件のレビュー)」 |
| 0件のとき | 「まだレビューが投稿された書籍がありません。」 |

コントローラーは、この Blade が表示に使う値（書籍・平均評価・レビュー件数）を渡す。
