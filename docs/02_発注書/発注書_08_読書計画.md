# 発注書 08 読書計画

読書計画の一覧・作成・編集・読了・削除と、計画の状態の定義を担当する。期日の3日後に自動で期限切れにする処理は 09 通知の担当。

- 合格の基準: `docs/03_検品表/08_読書計画.md`（この番号の全条件を1条件1行で並べた表）。この発注書に書かれていても検品表に無い作業は完成条件に含まれない

- 全機能に共通する動き（未ログイン時の誘導・エラー画面・入力エラー時の戻り方・成功メッセージの表示規則・削除済み書籍の扱いの原則・入力チェックの標準文言）: `docs/02_発注書/発注書_00_共通動作.md`

## 4. 作るもの

### 4-1. 状態（`App\Enums\ReadingPlanStatus`）

| 名前 | 値 | 表示 | 変わるきっかけ |
|---|---|---|---|
| `InProgress` | `in_progress` | 進行中・青のバッジ | 作成時 |
| `Completed` | `completed` | 完了・緑のバッジ | 「読了する」を押したとき（完了日時を記録） |
| `Expired` | `expired` | 期限切れ・赤のバッジ | 期日の3日後の0:00に、進行中のものが自動で変わる（09 通知の担当） |

期限切れになっても「読了する」「編集」「削除」はできる。期限切れの計画の期日を変えても、状態は期限切れのまま変えない（期日だけを更新する）。

### 4-2. 一覧（PG15）

| 項目 | 確定値 |
|---|---|
| 対象 | ログイン中の会員の計画だけ。書籍が削除済みでも表示する |
| 並び・件数 | 作成が新しい順に全件。ページ送りなし |
| 状態の絞り込み | 「状態:」のプルダウン（すべて／進行中／完了／期限切れ）。変えると即座に絞り込む。値は 4-1 の値 |
| 列 | 書籍・期日・完了日（無ければ「-」）・状態・操作 |
| 操作 | 完了以外の計画に「読了する」と編集画面へのリンク。すべての計画に削除（確認「本当に削除しますか？」） |
| 0件のとき | 「該当する読書計画はありません。」 |
| フラッシュ | 作成・更新・読了・削除の完了メッセージをここに出す |

### 4-3. 作成（PG16）

| 項目 | 確定値 |
|---|---|
| 書籍のプルダウン | 削除済みを除く全書籍をタイトル順 |
| 状態 | 進行中（`in_progress`）で作成する。作成者はログイン中の会員 |
| 成功時 | 読書計画一覧へ移動し、「読書計画を登録しました」 |

入力チェックは `App\Http\Requests\ReadingPlanStoreRequest`。

| 項目 | ルール | エラー文言 |
|---|---|---|
| 書籍 `book_id` | 必須・存在する書籍 | 「書籍を選択してください」「選択された書籍が存在しません」 |
| 書籍の重複 | 同じ書籍で進行中の計画が既にある場合は作成できない。完了・期限切れの計画しか無い書籍は作成できる。判定は `withValidator` で行う | 「この書籍は既に読書計画に登録されています」 |
| 期日 `target_date` | 必須・日付・今日以降 | 「期日を入力してください」「期日は本日以降の日付で指定してください」。日付でない値は共通の文言「target dateは正しい日付形式で入力してください。」 |

- 重複の判定をプルダウンから除く方式にしないのは、完了・期限切れの計画しか無い書籍まで選べなくなるため
- 「存在する書籍」の確認はテーブルを直接見るため、削除済みの書籍のIDも通る（画面のプルダウンには出ない）

### 4-4. 編集（PG17）・期日の変更

| 項目 | 確定値 |
|---|---|
| 変えられるもの | 期日だけ |
| 権限 | 作成者本人かつ完了していない計画のみ。それ以外は403 |
| 入力チェック | `App\Http\Requests\ReadingPlanUpdateRequest`。期日のルールと文言は 4-3 と同じ |
| 成功時 | 読書計画一覧へ移動し、「読書計画を更新しました」 |

### 4-5. 読了

| 項目 | 確定値 |
|---|---|
| 権限 | 作成者本人かつ完了していない計画のみ。それ以外は403（画面にボタンが出ない状態で直接送られた場合の防御） |
| 動き | 状態を `completed` にし、`completed_at` に日時を記録する |
| 成功時 | 読書計画一覧へ移動し、「読書計画を完了しました」 |

### 4-6. 削除

| 項目 | 確定値 |
|---|---|
| 権限 | 作成者本人のみ（完了済みも削除できる）。それ以外は403 |
| 動き | 物理削除 |
| 成功時 | 読書計画一覧へ移動し、「読書計画を削除しました」 |

### 4-7. 権限判定（`App\Policies\ReadingPlanPolicy`）

| メソッド | 許可する条件 |
|---|---|
| `update` | 作成者本人で、かつ完了していない |
| `complete` | 作成者本人で、かつ完了していない |
| `delete` | 作成者本人 |
