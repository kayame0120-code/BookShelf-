# 発注書 06 会員登録・ログイン

会員登録、ログイン、ログアウト、ログイン中に認証画面を開いたときの移動、ログインの試行回数の制限、ログイン失敗の文言、使用しない認証機能の無効化を担当する。

- 合格の基準: `docs/03_検品表/06_会員登録ログイン.md`（この番号の全条件を1条件1行で並べた表）。この発注書に書かれていても検品表に無い作業は完成条件に含まれない
- 共通の規則: `docs/共通ルール.md` の1章（着手前の確認・書かれていないことをしない・定義が無い場面での止まり方・変更してよい範囲・コミット・完了報告）と3章（文書の書き方）
- 提供モック・要件シート: 学校から配布された資料。提供モックは画面のひな形（Blade）、要件シートは作るものを定めた表で、所在と、実装との関係は `docs/00_提供資料/提供資料の所在.md` にある
- 全機能に共通する動き（未ログイン時の誘導・入力エラー時の戻り方・成功メッセージの表示規則・入力チェックの標準文言）: `docs/02_発注書/発注書_00_共通動作.md`

## 4. 作るもの

### 4-1. Fortify の設定（`config/fortify.php`）

| キー | 値 |
|---|---|
| `features` | 会員登録（`Features::registration()`）の1つだけ。パスワード再設定・メール確認・二要素認証は入れない（対応する Blade が提供物に無く、学校から配布された要件シート（所在は `docs/00_提供資料/提供資料の所在.md`）にも画面が無いため） |
| `home` | `/books`（Laravel 既定の `/home` はこのアプリに無く404になるため） |
| `username` | `email` |

ログイン・ログアウトは `features` に関係なく有効である。

### 4-2. 会員登録（PG13）

| 項目 | 確定値 |
|---|---|
| 成功時 | 自動でログインし、最初に開こうとした画面へ移動する。無ければ `/books` |
| メッセージ | 出さない |
| 入力ルールと文言を書く場所 | `App\Actions\Fortify\CreateNewUser@create` |

| 項目 | ルール | エラー文言 |
|---|---|---|
| お名前 `name` | 必須・文字列・255文字以内 | 「お名前を入力してください」「お名前は255文字以内で入力してください」 |
| メールアドレス `email` | 必須・メール形式・255文字以内・未登録 | 「メールアドレスを入力してください」「メールアドレスの形式が正しくありません」「メールアドレスは255文字以内で入力してください」「このメールアドレスは既に登録されています」 |
| パスワード `password` | 必須・文字列・8文字以上・確認用 `password_confirmation` と一致 | 「パスワードを入力してください」「パスワードは8文字以上で入力してください」「パスワード確認が一致しません」 |

お名前・パスワードの「文字列」のルールには個別の文言を置かず、共通の文言（例: 「名前は文字列で入力してください。」）を使う。

### 4-3. ログイン（PG12）とログアウト

| 項目 | 確定値 |
|---|---|
| 入力 | メールアドレスとパスワード |
| 成功時 | 最初に開こうとした画面へ移動する。無ければ `/books`。メッセージは出さない |
| 失敗時 | ログイン画面へ戻り、「メールアドレスまたはパスワードが正しくありません」（`lang/ja/auth.php` の `failed`） |
| 未入力 | 共通の文言「メールアドレスは必須です。」「パスワードは必須です。」 |
| ログアウト | ヘッダーのユーザー名のメニューから `POST /logout`。`/` へ移動する。メッセージは出さない |

### 4-4. ログインの試行回数の制限

`App\Providers\FortifyServiceProvider@boot` で、`RateLimiter::for('login', …)` に次の決まりを置く。

| 項目 | 確定値 |
|---|---|
| 上限 | 1分に5回（`Limit::perMinute(5)`） |
| 数える単位 | メールアドレスとIPの組（`by(` にメールアドレスとIPをつないだ値を渡す） |
| 超えたとき | 429。専用の画面・文言は作らず、Laravel 標準の表示のまま |

別のメールアドレスは別に数える。1分たてば再びログインできる。

### 4-5. ログイン中に認証画面を開いたとき

| 項目 | 確定値 |
|---|---|
| 部品 | `App\Http\Middleware\RedirectIfAuthenticated@handle`。`App\Http\Kernel` の別名 `guest` に結び付ける |
| 移動先 | `App\Providers\RouteServiceProvider::HOME`（値は `/books`） |
| 対象 | ログイン中に `GET /login`・`GET /register` を開いたとき |

### 4-6. 提供モックから変える箇所

| ファイル | 変えること |
|---|---|
| `resources/views/auth/login.blade.php` | 「会員登録」ボタンを削除する |
| `resources/views/auth/register.blade.php` | 「ログイン」ボタンを、ログイン画面へのテキストリンク「アカウントをお持ちの方」に変える |

どちらも、画面のデザインの指定（要件シートのデザインUI）を提供モックより優先する例外にあたる。ここに無い変更をしない。
