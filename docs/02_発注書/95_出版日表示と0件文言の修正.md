# 95 出版日表示と0件文言の修正（発注書）

## 0. 背景（発注書96の実装確認の結果）

| No | 確認できた事実 |
|---|---|
| K1 | ISBN検索の出版日の補完は、年のみ→`YYYY-01-01`、年月のみ→`YYYY-MM-01`、年月日→そのまま、無し・その他の形→空、の通りに動く。ただし、この補完を確かめるテストが無い |
| K2 | 出版日が `1905-01-01` の書籍で、編集画面の出版日入力欄が `value="1905-01-01 00:00:00"` になる。日付の入力欄はこの形を受け付けないため空欄で表示され、そのまま更新すると出版日が空で上書きされる |
| K3 | 書籍一覧で検索して0件のとき「書籍が登録されていません。」が表示される。要件シート シート7 J16 は「書籍が見つかりませんでした。」 |
