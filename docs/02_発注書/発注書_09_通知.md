## 4. 作るもの

### 4-1. 定期処理の登録

`App\Console\Kernel@schedule` に2つを登録する。時刻はアプリのタイムゾーン（`config/app.php` の `timezone` が Asia/Tokyo）で数える。

| コマンド | 実行 | 処理するクラス |
|---|---|---|
| `reading-plans:expire` | 毎日 0:00（`0 0 * * *`） | `App\Console\Commands\ExpireReadingPlans@handle` |
| `reading-plans:send-reminders` | 毎日 7:00（`0 7 * * *`） | `App\Console\Commands\SendReadingPlanReminders@handle` |

状態の更新と通知の送信は担当を分け、1つのコマンドにまとめない。判定が日単位なので、0:00 と 7:00 の間で日付をまたがない限り取りこぼしは起きない。

### 4-2. 期限切れにする処理 `reading-plans:expire`

| 項目 | 確定値 |
|---|---|
| 対象 | 状態が `in_progress` で、期日がちょうど3日前の計画 |
| 結果 | 状態を `expired` にする。通知は送らない |
| 失敗 | 1件の失敗はログに残し、残りの処理を続ける |

進行中の計画だけを対象にするので、何度実行しても結果は変わらない。

### 4-3. 通知を送る処理 `reading-plans:send-reminders`

| 種類（`App\Enums\NotificationTiming`） | 対象の計画 | 件名 | 本文 |
|---|---|---|---|
| `three_days_before` | `in_progress` で、期日が3日後 | 「読書計画のリマインダー」 | 「『書籍名』の期日まで残り3日です。」 |
| `on_due_date` | `in_progress` で、期日が今日 | 「読書計画の期日です」 | 「『書籍名』の期日は本日です。」 |
| `three_days_after` | `in_progress` または `expired` で、期日が3日前 | 「読書計画の期日が過ぎました」 | 「『書籍名』の期日から3日が経過したため、計画は自動的に「期限切れ」になりました。」 |

| 項目 | 確定値 |
|---|---|
| 送り先 | 計画の作成者 |
| 方式 | `App\Notifications\ReadingPlanReminder`。`via` は `database` だけを返す（DB に保存し、メールは送らない）。件名は `title`、本文は `body` が作る |
| 書籍が削除済みのとき | 書籍名を取得して通知する（`App\Models\ReadingPlan::book` を使う） |
| 送信済みの確認 | しない。同じ日に2回実行すると同じ通知が2通届く |
| 失敗 | 1件の失敗はログに残し、残りの処理を続ける |

**実行順序に依存する仕様**: 0:00 の処理で期限切れへ変わった計画は、同じ日の 7:00 に「3日後」の通知の対象になる。「3日後」の対象に `expired` を含めているのはこのためで、含めなければ 0:00 に期限切れになった計画に「3日後」の通知が届かない。この理由を `App\Console\Commands\SendReadingPlanReminders@handle` のコメントに書く。

### 4-4. 通知一覧（PG18）

| 項目 | 確定値 |
|---|---|
| 対象 | ログイン中の会員宛ての通知だけ |
| 並び・件数 | 新しい順に全件。ページ送りなし |
| 未読の表示 | 背景色と左端の色帯、「未読」バッジ、「既読にする」ボタン |
| 種類ごとの色 | 3日前: 青、当日: 黄、3日後: 赤（アイコンも種類ごとに変わる） |
| 0件のとき | 「通知はありません。」 |

### 4-5. 既読にする

| 項目 | 確定値 |
|---|---|
| 権限 | 自分宛ての通知のみ。`App\Http\Controllers\NotificationController@read` の中で、通知を取得してから送り先の会員IDを確かめる（所有者で絞って探すと他人の通知が見つからずに404になるため） |
| 他人宛ての通知 | 403 |
| 存在しないID | 404 |
| 成功時 | `notifications.read_at` に日時を入れ、元の画面に戻る。メッセージは出さない（未読バッジが消えることで状態を表す） |

送り先の種類（会員かどうか）は確かめず、送り先の会員IDだけを確かめる。

| 項目 | 確定値 |
|---|---|
| 表示 | ログイン中、通知ベルに未読件数を赤丸で出す |
| 0件のとき | 件数を出さない |
