# 99 要件シート照合調査（調査依頼）

## 1. 目的

実装を正として `docs/00_正本/` の要件シート（xlsx）を1回で改訂するための、事実の全量収集。
CCの仕事は次の3つだけ。

1. リポジトリのブランチ構成を全部記録し、調査対象のコミットを機械的に決める
2. 要件シートから照合台帳を §5 Step1b のスクリプトで機械生成し、全行に対象コミットの実装側の事実を記録する
3. 実装の全量を機械的に書き出す

- 一致・不一致の判定、修正案の作成、要件シートの編集はCCの仕事ではない（判定と改訂は設計チャット側が行う）
- 調査範囲は、全ブランチ＋対象コミットにある要件シートの全13シート・全セル・全行（件数は Step1b の生成結果で確定する）＋シート6の画像22枚＋対象コミットの実装の全ファイル。**範囲の選択・間引き・「代表的な箇所だけ」「怪しい箇所だけ」の抽出は禁止**。台帳にある行はすべて埋める

## 2. 対象

| 項目 | 値 |
|---|---|
| リポジトリ | このリポジトリ |
| 調査対象コミット | Step0 の B04 で決まる1コミット（全ブランチを含むコミット）。以後この1コミットだけを対象とする |
| 要件シート | 対象コミットの `docs/00_正本/` にある xlsx 1本（ファイル名は問わない） |
| 件数の基準 | Step1b のスクリプトが出力した各台帳のセル数・L行数（R26）。この件数を完了時の照合に使う |

## 3. 禁止事項

1. `app/` `routes/` `database/` `resources/` `config/` `lang/` `tests/` ほか実装ファイルの変更
2. 要件シート（xlsx）の変更
3. DBを変更するコマンドの実行（`migrate` `migrate:fresh` `migrate:rollback` `db:seed` `db:wipe` と、INSERT/UPDATE/DELETE/ALTER/DROP を含むSQL）。例外は §5 Step6 のテスト実行1回のみ
4. パッケージの追加・更新（`composer require` `composer update` `npm install` ほか）
5. `.env` の内容の出力（`APP_PORT` の1行だけは可。`.env.example` は出力してよい）。パスワードをコマンドに直接書くこと
6. commit・push・merge・rebase・reset・ブランチの作成と削除。git操作で許可するのは `fetch` と、Step0 の対象コミットへの `checkout --detach` と、Step7 の元のブランチへの `checkout` のみ
7. 台帳の「事実:」欄に判定語を自分の言葉で書くこと（一致／不一致／相違／ズレ／正しい／誤り／問題／OK／YES／NO／PASS／FAIL／合格／準拠／反映済み／想定通り）。コードや出力の引用に含まれる場合は引用なので可
8. 台帳のブロック・L行の削除、並べ替え、L行本文の書き換え

## 4. 停止条件（該当したら `QUESTIONS.md` に書いて停止）

1. Step0 開始時点で `git status --short --untracked-files=no` の出力が空でない（追跡中のファイルに未コミットの変更がある）。未追跡のファイル（`??` の行）は切り替えで消えないため停止理由にしない。B00 で一覧だけ記録する
2. B04 の出力が0行（全ブランチを含むコミットが存在しない＝並行して未統合の作業がある）
3. 対象コミットの `docs/00_正本/` にある xlsx が1本でない（R05 の出力行数が1でない）
4. Sail が起動しておらず、`./vendor/bin/sail up -d` でも起動しない

停止時は、それまでに記録した 実行結果.md と ブランチ差分/ を残したまま止まる。

出力は加工せず、コマンドと出力をそのまま貼る。出力が長くても切らない。

```bash
for r in $(git for-each-ref --format='%(refname)' refs/heads refs/remotes | grep -v '/HEAD$'); do
  echo "$r main側のみ/ブランチ側のみ: $(git rev-list --left-right --count refs/heads/main...$r)"
done

# B04（出力された行のコミットが調査対象。複数行が出た場合、全行が同じコミットを指す）
refs=$(git for-each-ref --format='%(refname)' refs/heads refs/remotes | grep -v '/HEAD$')
for t in $refs; do ok=1; for c in $refs; do git merge-base --is-ancestor "$c" "$t" || { ok=0; break; }; done; [ $ok = 1 ] && echo "包含: $t $(git rev-parse $t)"; done

# B05

for r in $(git for-each-ref --format='%(refname)' refs/heads refs/remotes | grep -v '/HEAD$'); do
  if ! git merge-base --is-ancestor "$r" refs/heads/main; then
    n=$(echo "${r#refs/}" | sed 's#/#__#g')
    echo "===== $r"; git log --oneline refs/heads/main..$r; git diff --stat refs/heads/main...$r
    git diff refs/heads/main...$r > "docs/04_検品結果/照合調査/ブランチ差分/$n.diff"
    echo "保存: ブランチ差分/$n.diff $(wc -l < "docs/04_検品結果/照合調査/ブランチ差分/$n.diff")行"
  fi
done

# B07（日本語・空白入りのファイル名をそのまま扱うため core.quotepath=off と while read を使う）
for r in $(git for-each-ref --format='%(refname)' refs/heads refs/remotes | grep -v '/HEAD$'); do
  git -c core.quotepath=off ls-tree -r --name-only "$r" -- docs/00_正本/ | grep -i '\.xlsx$' | while IFS= read -r p; do echo "$r $p $(git show "$r:$p" | sha256sum)"; done
done

# B08（xlsx を最初に追加したコミットの版を取り出す）
c=$(git -c core.quotepath=off log --all --diff-filter=A --reverse --format='%H' -- 'docs/00_正本/*.xlsx' | head -1)
p=$(git -c core.quotepath=off show --name-only --format='' "$c" -- 'docs/00_正本/*.xlsx' | head -1)
echo "初版コミット: $c $p"
git show "$c:$p" > docs/04_検品結果/照合調査/要件シート_初版.xlsx
sha256sum docs/04_検品結果/照合調査/要件シート_初版.xlsx
```

### Step1b 照合台帳の生成

台帳は手で作らない。下のスクリプトをリポジトリの外（`/tmp/gen_ledger.py`）にそのまま保存し、Python標準ライブラリだけで実行する（パッケージの導入は不要）。スクリプトの中身は変更しない。

```bash
cat > /tmp/gen_ledger.py <<'PYEOF'
import sys, zipfile, re, os
import xml.etree.ElementTree as ET
X = sys.argv[1]; OUT = sys.argv[2]
NS = {'m': 'http://schemas.openxmlformats.org/spreadsheetml/2006/main'}
R = '{http://schemas.openxmlformats.org/officeDocument/2006/relationships}id'
z = zipfile.ZipFile(X)
def si_text(si):
    out = []
    for ch in si:
        tag = ch.tag.split('}')[1]
        if tag == 't': out.append(ch.text or '')
        elif tag == 'r':
            for t in ch.findall('m:t', NS): out.append(t.text or '')
    return ''.join(out)
ss = []
if 'xl/sharedStrings.xml' in z.namelist():
    ss = [si_text(si) for si in ET.fromstring(z.read('xl/sharedStrings.xml')).findall('m:si', NS)]
wb = ET.fromstring(z.read('xl/workbook.xml'))
rels = {r.get('Id'): r.get('Target') for r in ET.fromstring(z.read('xl/_rels/workbook.xml.rels'))}
imgs = [('D7','image1.png'),('L7','image2.png'),('S7','image3.png'),('AA7','image4.png'),('D51','image5.png'),('L51','image6.png'),('S51','image7.png'),('Z51','image8.png'),('D75','image9.png'),('L75','image10.png'),('D98','image11.png'),('L98','image12.png'),('D122','image13.png'),('D159','image14.png'),('L159','image15.png'),('D182','image16.png'),('L182','image17.png'),('D203','image18.png'),('D233','image19.png'),('M233','image20.png'),('U233','image21.png'),('D257','image22.png')]
os.makedirs(OUT, exist_ok=True)
for i, sh in enumerate(wb.find('m:sheets', NS), 1):
    name = sh.get('name'); sid = f'S{i:02d}'
    target = rels[sh.get(R)].lstrip('/'); target = target if target.startswith('xl/') else 'xl/' + target
    root = ET.fromstring(z.read(target))
    blocks = []; cells = 0; lines = 0
    for row in root.iter('{%s}row' % NS['m']):
        for c in row.findall('m:c', NS):
            t = c.get('t'); v = c.find('m:v', NS); f = c.find('m:f', NS)
            if t == 's' and v is not None: val = ss[int(v.text)]
            elif t == 'inlineStr':
                isel = c.find('m:is', NS)
                if isel is None: continue
                val = si_text(isel)
            elif f is not None: val = '=' + (f.text or '')
            elif v is not None:
                val = v.text or ''
                if t in (None, 'n') and re.fullmatch(r'-?\d+\.0', val): val = val[:-2]
            else: continue
            ls = [l.rstrip() for l in val.split('\n') if l.strip()]
            if not ls: continue
            cells += 1
            b = [f'### {sid}!{c.get("r")}']
            for n, l in enumerate(ls, 1):
                lines += 1; b.append(f'- L{n}: {l}'); b.append('  - 事実: （未記入）')
            blocks.append('\n'.join(b))
    head = f'''# 照合台帳 {sid} {name}

- 対象xlsx: docs/00_正本/ の要件シート
- シート名: {name}
- セル数: {cells} ／ 行数（L）: {lines}''' + (f' ／ 画像: {len(imgs)}' if i == 6 else '') + '''
- 記入規則: docs/02_発注書/99_要件シート照合調査.md の §6
- このファイルのブロック・L行の削除、並べ替え、L行本文の編集は禁止。「事実:」行の記入と追加のみ行う。

---
'''
    body = '\n\n'.join(blocks)
    if i == 6:
        body += '\n\n---\n\n## 画像（シート6に貼付された画面画像 22枚）\n\n' + '\n\n'.join(f'### {sid}!IMG@{a}（xl/media/{m}）\n- 要素の列挙と事実: （未記入）' for a, m in imgs)
    title = name.split(' ', 1)[1] if ' ' in name else name
    open(os.path.join(OUT, f'台帳_{sid}_{title}.md'), 'w', encoding='utf-8').write(head + body + '\n')
    print(f'台帳_{sid}_{title}.md セル={cells} L行={lines}')
PYEOF
python3 /tmp/gen_ledger.py docs/00_正本/*.xlsx docs/04_検品結果/照合調査
cd docs/04_検品結果/照合調査 && sha256sum 台帳_*.md && cd -
```

実行結果.md に R26 として、`python3 --version` と上の2つのコマンドの出力を記録する。R26 に出た各台帳のセル数・L行数が、この調査の件数の基準になる。

### Step7 元のブランチへの復帰・機械検証・完了報告（完了報告.md）

以下を実行し、コマンドと出力をそのまま `完了報告.md` に記録する。

```bash
git branch --show-current && git rev-parse HEAD
cd docs/04_検品結果/照合調査
for f in 台帳_S*.md; do echo "$f L行=$(grep -c '^- L[0-9]*: ' "$f") 画像=$(grep -c '^### S06!IMG@' "$f") 未記入=$(grep -c '（未記入）' "$f") 事実行=$(grep -c '^  - 事実:' "$f")"; done
```

完了の条件は次の4つがすべて成り立つこと。

- 開始時のブランチに戻っている
- 各台帳の L行の数が R26 の出力と同じ
- 全台帳で 未記入=0
- 判定語grepでヒットした行が、すべてコード・出力の引用部分に含まれるもの（ヒットした行は完了報告.md に全件残す）

## 6. 台帳の記入規則

### 6-1. 単位

- L行1つにつき「事実:」を1つ以上書く。L行の中に主張（値・件数・桁数・遷移先・文言・ステータスコード・型・制約・手順）が複数あるときは、主張ごとに「事実:」行を分けて追加する
- 最初の「事実: （未記入）」を書き換え、2つ目以降は直下に `  - 事実: ` で始まる行を追加する

### 6-2. 事実の書き方（次の4形式のどれか）

| 形式 | 書き方 | 例 |
|---|---|---|
| コード | `相対パス:行番号` ＋ その行の抜粋（コピーしたまま） | `事実: app/Http/Controllers/BookController.php:52 return redirect()->route('books.show', $book)->with('success', '書籍を登録しました');` |
| 実行 | `実行結果.md Rnn` ＋ 該当する出力行の抜粋 | `事実: 実行結果.md R12 GET\|HEAD  books/create ... books.create › BookController@create` |
| 該当なし | 探したコマンドと、その出力（0件）をそのまま | `事実: 該当なし grep -rn "isbn/" routes/ app/ → 出力0件` |
| N/A-記述 | その行が、アプリの仕様・構成・環境・手順の結果を何も述べていない場合（講座の説明文、見出し、表の列名）。理由を1句添える | `事実: N/A-記述（表の列名）` |

- 「該当なし」は、探した場所とキーワードが分かる形で書く。探さずに「該当なし」と書くことは禁止
- 事実はすべて対象コミットのものを書く。他ブランチの内容は台帳に書かない（ブランチ差分/ に記録済み）
- 数値（件数・桁数・ページあたり件数・時刻・バージョン）は、実装側の値が抜粋に含まれるように引用する
- 文言（フラッシュ・エラーメッセージ・ラベル・ボタン名・空メッセージ）は、実装側の文字列を一字一句引用する
- 手順を述べる行（シート4のコマンド類ほか）は手順を再実行せず、現在の環境の状態を示すファイルの行または R07〜R25 の出力で書く
- 画面の表示内容を述べる行は、Blade の該当行と、その値を渡すコントローラーの行の両方を書く
- 同じ事実の再掲は `事実: 同上 S07!H13 L1` と参照してよい（参照先に実体が書かれていること）
- セル記述と実装が同じか違うかは書かない。記述に無い実装要素を見つけた場合も台帳には書かない（実装の全量は実装全文.txt と R12・R14・R16・R17 で収集済み）

### 6-3. 画像ブロック（台帳_S06 の末尾22件）

1. `/tmp/xlsx_media/` の該当画像を開く
2. 「要素の列挙と事実: （未記入）」の行を `- 対応Blade: resources/views/...` に書き換える
3. 画像に写っている要素（文字列・見出し・ボタン・リンク・入力欄とそのラベル／placeholder・選択肢・表の列・アイコン・バッジ・空メッセージ）を、画像の上から下、左から右の順に全部 `- E1: 〜` `- E2: 〜` と列挙する
4. 各E行の直下に、6-2 の形式で「事実:」を書く（Blade の該当行）
