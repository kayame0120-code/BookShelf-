# 97 決定理由照合調査（調査依頼）

## 1. 目的

技術決定書で「理由：記録なし」になっている19件について、旧docs（リポジトリの `docs/` と `CLAUDE.md`）に残っている記録を**機械的な全文検索で全件**書き出す。
CCの仕事は、下の表の検索を全件実行し、出力をそのまま記録することだけ。どの記録が理由に当たるかの判定・要約・取捨選択はしない（判定は設計チャット側が行う）。

## 2. 対象

- リポジトリの現在の作業ツリーで、git管理下のファイル
- 検索範囲: `docs/` と `CLAUDE.md`。ただし調査の成果物と調査依頼そのもの（`docs/04_検品結果/照合調査/`・`docs/04_検品結果/仕様抽出/`・`docs/02_発注書/97_*`・`98_*`・`99_*`）は除く
- 成果物の置き場所: `docs/04_検品結果/理由照合/`

## 3. 禁止事項

1. ファイルの変更（成果物フォルダへの書き込みのみ可）
2. commit・push・ブランチ操作
3. 検索パターン・検索範囲の変更、出力の省略・要約・並べ替え
4. 判定語（該当・一致・不一致・関係なし ほか）を書くこと

## 4. 手順

### Step1 旧docsの一覧

```bash
mkdir -p docs/04_検品結果/理由照合
git -c core.quotepath=off ls-files -- docs CLAUDE.md ':!docs/04_検品結果/照合調査' ':!docs/04_検品結果/仕様抽出' > docs/04_検品結果/理由照合/00_対象ファイル一覧.txt
wc -l docs/04_検品結果/理由照合/00_対象ファイル一覧.txt
```

### Step2 19件の検索

下のスクリプトをそのまま実行する。1件につき1ファイル、前後3行付きで全ヒットを書き出す。

```bash
cd "$(git rev-parse --show-toplevel)"
OUT=docs/04_検品結果/理由照合
EX=(':!docs/04_検品結果/照合調査' ':!docs/04_検品結果/仕様抽出' ':!docs/02_発注書/97_*' ':!docs/02_発注書/98_*' ':!docs/02_発注書/99_*')
UI='デザインUI|デザイン優先|モック|提供Blade|frozen'
q() { # $1=番号 $2=項目 $3=検索パターン
  f="$OUT/$1.md"
  { echo "# $1 $2"; echo; echo "検索パターン: \`$3\`"; echo; echo '```'
    git -c core.quotepath=off grep -n -I -C3 -E "$3" -- docs CLAUDE.md "${EX[@]}"
    echo "終了コード: $?"; echo '```'; } > "$f"
  echo "$1 ヒット行数=$(git -c core.quotepath=off grep -c -I -E "$3" -- docs CLAUDE.md "${EX[@]}" | awk -F: '{s+=$NF} END{print s+0}')"
}
q 01_TD-01 "画面遷移" 'リダイレクト|遷移先|redirect|intended'
q 02_TD-02 "フラッシュ" 'フラッシュ|flash|with\(.success|session\(.success'
q 03_TD-03 "認可" 'Policy|ポリシー|認可|所有者|abort\(403'
q 04_TD-04 "バリデーション" 'FormRequest|バリデーション|重複制御|1000文字|255文字'
q 05_TD-05 "エラー文言" 'エラーメッセージ|エラー文言|messages\(\)|validation\.php|lang/ja'
q 06_TD-07 "API詳細" 'per_page|ページネーション|20件|10件|BookResource|BookListResource'
q 07_TD-08 "Sanctum" 'Sanctum|トークン|createToken|personal_access'
q 08_TD-09 "読書計画・通知" '期限切れ|expired|リマインダー|dailyAt|after_or_equal|3日'
q 09_TD-11 "APIだけISBN・出版日を必須" 'nullable|StoreApiBookRequest|UpdateApiBookRequest|ISBN.{0,20}必須|出版日.{0,20}必須'
q 10_TD-18 "期限切れと通知の時刻" '00:00|0:00|07:00|7:00|同時に|同時刻'
q 11_TD-20 "エラー画面" 'errors/|403\.blade|404\.blade|419|500\.blade|503|エラー画面|Handler'
q 12_TD-21 "Fortifyの機能" 'Fortify|features|resetPasswords|emailVerification|twoFactor|パスワード再設定|パスワードリセット'
q 13_TD-22_login "login画面" "login\.blade|会員登録ボタン|$UI"
q 14_TD-22_register "register画面" "register\.blade|アカウントをお持ち|$UI"
q 15_TD-22_form "_form" "_form|出版日の初期値|published_date.{0,40}format|$UI"
q 16_TD-22_index "書籍一覧画面" "books/index|検索結果|評価順|評価が高い順|書籍が見つかりませんでした|書籍が登録されていません|$UI"
q 17_TD-22_favorites "お気に入り一覧画面" "favorites/index|未登録|ストレッチ|$UI"
q 18_TD-22_reports "レポート画面" "reports/index|評価分布|$UI"
q 19_TD-22_pagination "ページ送り" "pagination|ページ送り|$UI"
```

### Step3 完了報告

`docs/04_検品結果/理由照合/完了報告.md` に、Step1 の `wc -l` の出力、Step2 でスクリプトが表示した19行（番号とヒット行数）、`ls -la docs/04_検品結果/理由照合` の出力をそのまま記録する。

完了の条件: `docs/04_検品結果/理由照合/` に `00_対象ファイル一覧.txt` と `01_TD-01.md`〜`19_TD-22_pagination.md` の19本と完了報告.md があり、19本すべての末尾に「終了コード:」の行がある（ヒット0件の場合は終了コード1になる。それもそのまま記録する）。
