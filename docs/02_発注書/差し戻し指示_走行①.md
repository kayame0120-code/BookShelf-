## 指示

`boot()` 内の `Fortify::authenticateUsing(...)` クロージャを除去し、Fortify標準のログイン認証（発注書 §3-1(d) 指定の boot() 定義どおり）に戻すこと。

除去後、以下を確認:

- メール形式不正時の表示が独自メッセージでなく `lang/ja/auth.php` の `failed`（メールアドレスまたはパスワードが正しくありません）に統一されていること
- 正しいメール・誤パスワードでも同じ `failed` が表示されること（挙動の一本化。専用メッセージとの分岐をなくす）
- `email: required,email` / `password: required,string` を独自 Validator で検証していたロジックを丸ごと削除し、Fortify 標準のバリデーション経路に委ねること
