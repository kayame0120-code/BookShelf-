## 抽出方法
- スクリプト `/tmp/xlsx_extract.py`：`docs/00_正本/片倉_菖さん_新模擬案件_Bookshelf_要件シート (1).xlsx` を `zipfile` で開き、`xl/sharedStrings.xml` を配列化、各 `xl/worksheets/sheetN.xml` の `<row r>`／`<c r t>` を走査し、`t="s"`（共有文字列）・`t="inlineStr"`・数値をセルアドレス付きで `セルアドレス<TAB>repr(値)` 形式で出力（要約なし）。
- 実行例：`python3 /tmp/xlsx_extract.py sheet7 40 90` 等。
- シート名対応：sheet5=画面設計 / sheet7=機能要件 / sheet8=バリデーションルール / sheet11=データ要件 / sheet12=テーブル仕様書。
