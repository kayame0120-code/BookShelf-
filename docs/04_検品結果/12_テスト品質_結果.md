```
  Http/Middleware/TrustHosts ............................................ 0.0%

```

`docs/04_検品結果/カバレッジ除外リスト.md` の項目との対応:

| 明細の行 | 除外リストの項目 | クラスに書かれたメソッド（ソースの現物） |
|---|---|---|
| `Http/Middleware/TrustHosts` 0.0% | `App\Http\Middleware\TrustHosts@hosts` | `public function hosts(): array` の1つだけ |
| `Providers/BroadcastServiceProvider` 0.0% | `App\Providers\BroadcastServiceProvider@boot` | `public function boot(): void` の1つだけ |

除外リストが理由に挙げる登録行のコメントアウトは、現物で次のとおり。

```
$ grep -n 'TrustHosts\|BroadcastServiceProvider' app/Http/Kernel.php config/app.php
config/app.php:168:        // App\Providers\BroadcastServiceProvider::class,
app/Http/Kernel.php:17:        // \App\Http\Middleware\TrustHosts::class,
```

0.0% の2本は、どちらもクラスに書かれたメソッドが1つだけで、そのメソッドが除外リストに載っている。除外リストに載っていない未カバーの範囲は無い。明細は割合だけを出力し未カバーの行番号を出力しないため、突き合わせはクラスとメソッドの単位で行った。
