## G. エラー応答の日本語化
- G-1（401）：B-1/B-2/B-3 のとおり message キーを持つ日本語JSON `{"message":"認証が必要です。"}`。英語 "Unauthenticated." の露出なし。
- G-2（403）：D-1/D-2 のとおり message キーを持つ日本語JSON `{"message":"この操作を実行する権限がありません。"}`。
Handler の該当実装（app/Exceptions/Handler.php）：
```php
$this->renderable(function (AuthenticationException $e, Request $request) {
    if ($request->is('api/*')) {
        return response()->json(['message' => '認証が必要です。'], 401);
    }
});
$this->renderable(function (AccessDeniedHttpException $e, Request $request) {
    if ($request->is('api/*')) {
        return response()->json(['message' => 'この操作を実行する権限がありません。'], 403);
    }
});
```
