# カバレッジ除外リスト

テストのカバレッジ計測で未カバーのまま残る行のうち、テストを書かずに残してよいものを、理由とともに一覧にしたもの。置き場所と役割は `docs/02_発注書/発注書_12_テスト品質.md`（テスト件数・カバレッジ・このリストの置き場所を定めた発注書）の「3. テスト」に従う。

## 測った条件

- Sail のアプリのコンテナを、カバレッジ計測を有効にして起動する: `SAIL_XDEBUG_MODE=coverage ./vendor/bin/sail up -d --force-recreate laravel.test`
- 計測のコマンド: `sail artisan test --coverage`
- 結果: テスト 181件すべて通過、カバレッジの合計（`Total`）99.3%

## 除外してよい条件

`CLAUDE.md`（このプロジェクトの実装・検品の恒久ルール）の 13-A-4 は、未カバーのまま残してよい行を次のいずれかに当たり、理由を1行で説明できるものに限っている。

- 16章で「残す」と確定した死んだコード
- フレームワークが自動生成し、アプリのどのルート・どの画面からも到達しないコード

`CLAUDE.md` の 16章は、フレームワークが標準で生成したクラス・設定を、使わないという理由だけで削除せず、呼び出さない・参照しない・公開しないことで対処すると定めている。

このリストに載っていない未カバー行は、`QUESTIONS.md`（未定義事項を記録し片倉の裁定を待つファイル）に記録している。
