# 検品表 01 書籍

- 対象の発注書: `docs/02_発注書/発注書_01_書籍.md`（この番号で何を作るかを書いた実装指示書）
- 共通の規則: `docs/共通ルール.md` の2章（証拠を集める条件・判定語を書かない原則・判定の主体・期待値の基準・確認方法の書き方・差し戻し）
- 提供モック・要件シート: 学校から配布された資料。提供モックは画面のひな形（Blade）、要件シートは作るものを定めた表で、所在と、実装との関係は `docs/00_提供資料/提供資料の所在.md` にある
- 材料: 機能仕様書 1章（書籍の一覧・詳細・登録・編集・削除・復元・ISBNからの自動入力）・0章（削除済み書籍の扱い）、全体仕様書 3章（PG01〜PG04）・4章（No 001・010〜017・019）・6章（books の論理削除）、技術決定書 TD-10〜TD-17・TD-31〜TD-33
- 担当ルート: No 001・010〜017・019 ／ 画面: PG01〜PG04
- 確認方法と期待値に出てくる `$` で始まる名前は、下の「確認に使うもの」の準備で値を入れた変数である。期待値はその変数の値に置き換えて照合する
- 行の見方: 「確認方法」を実行して得た生の結果が「期待値」と一致すれば YES、一致しなければ NO と判定する。判定は共通ルール2-3に従い、証拠を集めたセッションの外で行う

## 確認に使うもの

- 確認の前に `sail artisan migrate:fresh --seed` を実行し、初期データの直後の状態から始める。行は上から順に確認する（前の行の操作が後の行の前提になる）
- 検品用の会員は会員登録画面（`/register`）で作る。検品用の書籍のタイトルには実行ごとに変わる番号（`$STAMP`）を入れ、初期データの書籍と混ざらないようにする
- 外部からの呼び出しで確かめられない2つの挙動（未ログインの書き込みがログイン画面へ移ること、Google Books API の応答ごとの結果）は、下のテストコードで確かめる。トークン検証（CSRF）がログインの確認より先に働き、外部から送ると419になってログイン画面への移動を観測できないため、テストではトークン検証を外して呼ぶ。Google Books API は実際の通信をせず、応答を差し替えて呼ぶ
- テストコードは `tests/Feature/Inspection01Test.php` として置き、`sail artisan test --filter=Inspection01Test` を実行した出力を証拠にする。実行の後にこのファイルを削除し、`git status --porcelain` の出力が空であることを証拠の末尾に貼る

```bash
export LC_ALL=C.UTF-8
BASE=http://localhost            # アプリのURL（Sail の既定値）
STAMP=$(date +%s)
G=/tmp/jarG; rm -f $G            # 一度もログインしない利用者の cookie 保存先
tk()    { sail artisan tinker --execute="$1"; }
uid()   { tk "echo App\Models\User::where('email','$1$STAMP@example.com')->value('id');"; }
token_from() { curl -s -c "$1" -b "$1" "$BASE$2" | grep -o 'name="_token" value="[^"]*"' | head -1 | sed 's/.*value="//;s/"$//'; }
login_as() { curl -s -o /dev/null -c "$1" -b "$1" -X POST "$BASE/register" \
  --data-urlencode "_token=$(token_from "$1" /register)" --data-urlencode "name=検品会員$2" \
  --data-urlencode "email=$2$STAMP@example.com" --data-urlencode "password=password123" \
  --data-urlencode "password_confirmation=password123"; }
page()  { curl -s -c "$1" -b "$1" "$BASE$2"; }
has()   { page "$1" "$2" | grep -cF -- "$3"; }            # 本文に $3 を含む行の数
near()  { page "$1" "$2" | grep -B3 -A3 -F -- "$3"; }      # $3 の前後3行
st()    { curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' -c "$1" -b "$1" "$BASE$2"; }
# submit <cookie> <トークンを取る画面> <POST|PUT|PATCH|DELETE> <送信先> [項目=値 ...]
# 送信結果を "STATUS=… LOCATION=…" で出力し、移動先（移動が無ければ応答そのもの）の本文を /tmp/last.html に保存する
submit() {
  local jar=$1 form=$2 method=$3 action=$4; shift 4
  local args=(--data-urlencode "_token=$(token_from "$jar" "$form")" --data-urlencode "_method=$method") kv
  for kv in "$@"; do args+=(--data-urlencode "$kv"); done
  local res; res=$(curl -s -o /tmp/resp.html -w '%{http_code} %{redirect_url}' -c "$jar" -b "$jar" -e "$BASE$form" -X POST "$BASE$action" "${args[@]}")
  local loc=${res#* }
  echo "STATUS=${res%% *} LOCATION=$loc"
  if [ -n "$loc" ]; then curl -s -c "$jar" -b "$jar" "$loc" > /tmp/last.html; else cp /tmp/resp.html /tmp/last.html; fi
}
```

mkbook() { local jar=$1; shift; local r; r=$(submit "$jar" /books/create POST /books "$@"); echo "${r##*/}"; }

titles() { page "$1" "$2" | grep -oE "T$STAMP-?[a-z0-9]+" | awk '!s[$0]++' | tr '\n' ' '; echo; }

card_titles() { page "$1" "$2" | tr -d '\n' | grep -oE '<h3[^>]*>[^<]*</h3>' | grep -oE "T$STAMP-?[a-z0-9]+" | awk '!s[$0]++' | tr '\n' ' '; echo; }
err()    { grep -cF -- "$1" /tmp/last.html; }

for p in "$BB 5" "$BA 3" "$BC 1"; do set -- $p; submit /tmp/jarA /books/$1 POST /books/$1/reviews "rating=$2" > /dev/null; done
git clone --depth 1 -b advanced https://github.com/coachtech-prepared-file/Preparedblade-mockcase-BookShelf.git /tmp/blade-advanced
MV=$(find /tmp/blade-advanced -type d -path '*resources/views' | head -1)   # 提供モックの resources/views
for i in 01 02 03 04 05 06 07 08; do mkbook /tmp/jarA "title=${K}p$i" "author=検品著者" "genres[]=$GID" > /dev/null; done   # キーワード $K に一致する書籍を合計11冊にする（$K- に一致するのは a・b・c の3冊だけ）

### テストコード（`tests/Feature/Inspection01Test.php`）

```php
<?php

namespace Tests\Feature;

use App\Http\Middleware\VerifyCsrfToken;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Illuminate\Http\Client\ConnectionException;
use Illuminate\Support\Facades\Http;
use Tests\TestCase;

class Inspection01Test extends TestCase
{
    use RefreshDatabase;

    private const ISBN = '9784000000001';

    private function found(array $info): void
    {
        Http::fake(['*' => Http::response(['totalItems' => 1, 'items' => [['volumeInfo' => $info]]], 200)]);
    }

    private function search()
    {
        return $this->actingAs(User::factory()->create())->getJson('/books/isbn/'.self::ISBN);
    }

    public function test_guest_post_books_redirects_to_login(): void
    {
        $this->withoutMiddleware(VerifyCsrfToken::class)->post('/books', [])->assertRedirect('/login');
    }

    public function test_guest_put_book_redirects_to_login(): void
    {
        $this->withoutMiddleware(VerifyCsrfToken::class)->put('/books/1', [])->assertRedirect('/login');
    }

    public function test_guest_delete_book_redirects_to_login(): void
    {
        $this->withoutMiddleware(VerifyCsrfToken::class)->delete('/books/1')->assertRedirect('/login');
    }

    public function test_guest_restore_book_redirects_to_login(): void
    {
        $this->withoutMiddleware(VerifyCsrfToken::class)->patch('/books/1/restore')->assertRedirect('/login');
    }

    public function test_isbn_found_fills_fields(): void
    {
        $this->found(['title' => '検品タイトル', 'authors' => ['著者一', '著者二'], 'description' => '検品説明',
            'imageLinks' => ['thumbnail' => 'https://example.com/t.jpg'], 'publishedDate' => '2012-06-15']);
        $this->search()->assertOk()->assertJson(['title' => '検品タイトル', 'author' => '著者一、著者二',
            'description' => '検品説明', 'image_url' => 'https://example.com/t.jpg',
            'published_date' => '2012-06-15', 'published_date_padded' => false]);
    }

    public function test_isbn_year_month_is_padded(): void
    {
        $this->found(['title' => 'T', 'publishedDate' => '2012-06']);
        $this->search()->assertOk()->assertJson(['published_date' => '2012-06-01', 'published_date_padded' => true]);
    }

    public function test_isbn_year_is_padded(): void
    {
        $this->found(['title' => 'T', 'publishedDate' => '2012']);
        $this->search()->assertOk()->assertJson(['published_date' => '2012-01-01', 'published_date_padded' => true]);
    }

    public function test_isbn_other_date_format_is_empty(): void
    {
        $this->found(['title' => 'T', 'publishedDate' => 'June 2012']);
        $this->assertEmpty($this->search()->assertOk()->json('published_date'));
    }

    public function test_isbn_not_found_returns_404(): void
    {
        Http::fake(['*' => Http::response(['totalItems' => 0], 200)]);
        $this->search()->assertStatus(404)->assertExactJson(['message' => '該当する書籍が見つかりませんでした']);
    }

    public function test_isbn_api_error_returns_502(): void
    {
        Http::fake(['*' => Http::response([], 500)]);
        $this->search()->assertStatus(502)->assertExactJson(['message' => '書籍情報の取得に失敗しました']);
    }

    public function test_isbn_connection_failure_returns_502(): void
    {
        Http::fake(fn () => throw new ConnectionException('検品用の通信失敗'));
        $this->search()->assertStatus(502)->assertExactJson(['message' => '書籍情報の取得に失敗しました']);
    }
}
```
