# 検品表01 修正パッチ — H-2行のみ

`docs/03_検品表/01_土台認証.md` の H-2 行を以下に差し替える。他の行（A〜G, H-1, H-3〜H-6, I-1, I-2）は変更不要。

## 変更理由

現行の検証手段 `git diff main --stat -- resources/` は以下の理由で対象を誤検知する:

- `resources/views/` は git 管理外（untracked）のため、モック本体の改変があっても検知できない（偽陰性）
- ビルドエントリポイント（`app.css` 等）の未コミット環境設定変更を、モック改変と誤って拾う（偽陽性・検品結果①で実際に発生）

frozen 宣言の正本はモックリポジトリ（`Preparedblade-mockcase-BookShelf` basic ブランチ）側にあるため、frozen性の検証は git 内部の差分ではなく外部リポジトリとの直接突合で行う。

## 差し替え後の行

| No. | 判定基準 | 検証手段 |
|---|---|---|
| H-2 | Bladeモック（`resources/views/`）が frozen 宣言後に改変されていない | モック basic ブランチを一時ディレクトリへ再clone → `diff -r <一時clone>/resources/views resources/views` の出力が空 |

## 検証コマンド例

```bash
git clone --depth 1 -b basic <モックリポジトリURL> /tmp/mock-basic-check
diff -r /tmp/mock-basic-check/resources/views resources/views
rm -rf /tmp/mock-basic-check
```
