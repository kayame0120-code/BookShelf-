## 確認に使うもの

- 確認の前に `sail artisan migrate:fresh --seed` を実行し、初期データの直後の状態から始める。行は上から順に確認する（前の行の操作が後の行の前提になる）
- レビューの初期データは書籍ごとの件数と評価が実行のたびに変わる。そのため期待するランキングは固定の値で書かず、仕様（削除済みを除き、レビューが1件以上ある書籍を、平均の高い順・同点は書籍IDの小さい順に10件）どおりにDBから組み立てた並びと、画面の並びを突き合わせる

```bash
export LC_ALL=C.UTF-8
BASE=http://localhost            # アプリのURL（Sail の既定値）
STAMP=$(date +%s)
G=/tmp/jarG; rm -f $G            # 一度もログインしない利用者の cookie 保存先
tk()    { sail artisan tinker --execute="$1"; }
uid()   { tk "echo App\Models\User::where('email','$1$STAMP@example.com')->value('id');"; }
token_from() { curl -s -c "$1" -b "$1" "$BASE$2" | grep -o 'name="_token" value="[^"]*"' | head -1 | sed 's/.*value="//;s/"$//'; }
login_as() { curl -s -o /dev/null -c "$1" -b "$1" -X POST "$BASE/register" \
  --data-urlencode "_token=$(token_from "$1" /register)" --data-urlencode "name=検品会員$2" \
  --data-urlencode "email=$2$STAMP@example.com" --data-urlencode "password=password123" \
  --data-urlencode "password_confirmation=password123"; }
page()  { curl -s -c "$1" -b "$1" "$BASE$2"; }
has()   { page "$1" "$2" | grep -cF -- "$3"; }            # 本文に $3 を含む行の数
near()  { page "$1" "$2" | grep -B3 -A3 -F -- "$3"; }      # $3 の前後3行
st()    { curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' -c "$1" -b "$1" "$BASE$2"; }
# submit <cookie> <トークンを取る画面> <POST|PUT|PATCH|DELETE> <送信先> [項目=値 ...]
# 送信結果を "STATUS=… LOCATION=…" で出力し、移動先（移動が無ければ応答そのもの）の本文を /tmp/last.html に保存する
submit() {
  local jar=$1 form=$2 method=$3 action=$4; shift 4
  local args=(--data-urlencode "_token=$(token_from "$jar" "$form")" --data-urlencode "_method=$method") kv
  for kv in "$@"; do args+=(--data-urlencode "$kv"); done
  local res; res=$(curl -s -o /tmp/resp.html -w '%{http_code} %{redirect_url}' -c "$jar" -b "$jar" -e "$BASE$form" -X POST "$BASE$action" "${args[@]}")
  local loc=${res#* }
  echo "STATUS=${res%% *} LOCATION=$loc"
  if [ -n "$loc" ]; then curl -s -c "$jar" -b "$jar" "$loc" > /tmp/last.html; else cp /tmp/resp.html /tmp/last.html; fi
}
```

```bash
mkbook() { local jar=$1; shift; local r; r=$(submit "$jar" /books/create POST /books "$@"); echo "${r##*/}"; }
# expect_ids — 仕様どおりの上位10件の書籍IDを、上から順に1行で出力する
expect_ids() { tk 'echo DB::table("reviews")->join("books","books.id","=","reviews.book_id")->whereNull("books.deleted_at")->groupBy("books.id")->selectRaw("books.id, AVG(reviews.rating) a")->orderByDesc("a")->orderBy("books.id")->limit(10)->pluck("id")->implode(" ");'; }
eligible()   { tk 'echo DB::table("reviews")->join("books","books.id","=","reviews.book_id")->whereNull("books.deleted_at")->distinct()->count("books.id");'; }
avg_of()     { tk "echo DB::table('reviews')->where('book_id',$1)->avg('rating');"; }
cnt_of()     { tk "echo DB::table('reviews')->where('book_id',$1)->count();"; }
title_of()   { tk "echo App\Models\Book::withTrashed()->find($1)->title;"; }
# screen_order <ID...> — 渡した書籍のタイトルが画面に最初に出る行の番号を、渡した順に1行で出力する（出ない書籍は 0）
screen_order() { page $G /ranking > /tmp/rank.html; for b in "$@"; do t=$(title_of $b); n=$(grep -nF -- "$t" /tmp/rank.html | head -1 | cut -d: -f1); echo -n "${n:-0} "; done; echo; }
ascending()  { awk '{ok=1; for(i=2;i<=NF;i++) if($i<=$(i-1)) ok=0; for(i=1;i<=NF;i++) if($i==0) ok=0; print (ok?"ascending":"not-ascending")}'; }

login_as /tmp/jarA A
git clone --depth 1 -b advanced https://github.com/coachtech-prepared-file/Preparedblade-mockcase-BookShelf.git /tmp/blade-advanced
MV=$(find /tmp/blade-advanced -type d -path '*resources/views' | head -1)   # 提供モックの resources/views
GID=$(tk 'echo App\Models\Genre::orderBy("id")->value("id");')
BN=$(mkbook /tmp/jarA "title=N$STAMP-none" "author=X" "genres[]=$GID")   # レビューが0件の書籍
```

## 1. ルートと権限

| 行 | 条件 | 確認方法 | 期待値 |
|---|---|---|---|
| 05-01 | ランキングのルート `GET /ranking` が `RankingController@index` で、ルート名が `ranking.index` である | `sail artisan route:list --name=ranking --except-vendor` | 出力の1行に、`GET`・`ranking`・`ranking.index`・`RankingController@index` がそろって含まれる |
| 05-02 | 未ログインで `GET /ranking`（PG11）を開くと 200 | `st $G /ranking` | `200 ` |
| 05-03 | 見出し「評価ランキング TOP 10」が出る | `has $G /ranking '評価ランキング TOP 10'` | 1以上 |

## 2. 並びと件数（初期データの状態）

| 行 | 条件 | 確認方法 | 期待値 |
|---|---|---|---|
| 05-04 | 出る書籍の数が、対象の書籍の数と10のうち小さいほう | `page $G /ranking \| grep -o '件のレビュー)' \| wc -l; E=$(eligible); echo $(( E < 10 ? E : 10 ))` | 2行の数が同じ |
| 05-05 | 仕様どおりの上位の書籍が、すべて画面に、仕様どおりの順で出る | `screen_order $(expect_ids) \| ascending` | `ascending` |
| 05-06 | レビューが0件の書籍が出ない | `screen_order $BN` | `0 ` |
| 05-07 | 1位の書籍の平均評価が、小数2桁の形で出る | `T=$(expect_ids \| awk '{print $1}'); grep -cF "$(printf '%.2f' $(avg_of $T))" /tmp/rank.html` | 1以上 |
| 05-08 | 1位の書籍の平均評価が、小数1桁の形でも出る | `T=$(expect_ids \| awk '{print $1}'); grep -cF "$(printf '%.1f' $(avg_of $T))" /tmp/rank.html` | 1以上 |
| 05-09 | 1位の書籍のレビュー件数が「(N件のレビュー)」の形で出る | `T=$(expect_ids \| awk '{print $1}'); grep -cF "($(cnt_of $T)件のレビュー)" /tmp/rank.html` | 1以上 |
| 05-10 | ★が出る | `grep -c '★' /tmp/rank.html` | 1以上 |

## 3. 削除済みの書籍を除く

| 行 | 条件 | 確認方法 | 期待値 |
|---|---|---|---|
| 05-11 | 1位の書籍を削除済みにすると、その書籍が画面から消える | `T=$(expect_ids \| awk '{print $1}'); echo $T > /tmp/top; tk "App\Models\Book::find($T)->delete();"; screen_order $(cat /tmp/top)` | 最後の行が `0 ` |
| 05-12 | 削除のあとも、仕様どおりの上位の書籍が、すべて画面に、仕様どおりの順で出る | `screen_order $(expect_ids) \| ascending` | `ascending` |
| 05-13 | `App\Http\Controllers\RankingController@index` が、同点のとき書籍IDの小さい順に並べる指定を持つ | `sed -n '/function index/,/^    }/p' app/Http/Controllers/RankingController.php` | 出力に、平均評価の降順の指定に続けて、書籍IDの昇順の指定がある |
| 05-14 | `App\Http\Controllers\RankingController@index` が、上位10件に絞る指定を持つ | 同上 | 出力に `10` を件数の上限とする指定（`limit(10)` または `take(10)`）がある |
