## 証拠収集の実施条件

- 実装を行ったCCセッションとは別の、文脈ゼロの新規セッションで証拠を収集する。
- 渡してよいのは①`CLAUDE.md`（自動読込） ②本検品表と対の発注書 ③実装済みコードとテストコードの3点のみ。
- CCは各行に対応する生の実行結果のみを記入する。「正しく動作した」「問題ない」「YES」「PASS」「合格」といった判定・評価を意味する語は一切書かない。
- 判定（YES/NO）はこのチャットが証拠ファイルと本表を突き合わせて行う。1行でもNOがあれば走行⑭は不合格。
- テストの網羅性を確認する行は、テストコードの該当箇所（テストメソッド名・アサーション行）を証拠として引用させる。テスト実行の合否だけでは網羅性を判定しない。

## 証拠収集前に一度だけ実行するコマンド（出力を証拠ファイルに貼る）

```bash
git branch --show-current
git log --oneline -5
sail bin pint --test
sail artisan test
sail artisan test --coverage
ls -la tests/Feature/ tests/Unit/
```

`sail artisan test --coverage` の出力は中略せず、全クラスの行（0.0%・部分カバレッジの行番号を含む）をそのまま貼ること。カバレッジ明細を省略した証拠は根拠不足として扱う。
