## 確認に使うもの

- この番号は他の番号の検品がすべて終わってから行う。テストの実行は他の番号の確認に使ったデータに触れない前提だが、念のため最後に置く
- カバレッジの計測には、Sail のコンテナでカバレッジの計測機能（Xdebug のカバレッジモード）を有効にした状態で `sail artisan test --coverage` を実行する
- テストファイルと機能軸の対応一覧は、発注書 12（`docs/02_発注書/発注書_12_テスト品質.md`）の表にある。その表と、実在するファイルを突き合わせる

```bash
export LC_ALL=C.UTF-8
tk()   { sail artisan tinker --execute="$1"; }
ORDER=docs/02_発注書/発注書_12_テスト品質.md
real_tests() { (cd tests && find Feature Unit -name '*.php' | sort); }
listed_tests() { grep -oE '`(Feature|Unit)/[A-Za-z0-9_/]+\.php`' $ORDER | tr -d '`' | sort -u; }
# models_missing — App\Models の5本で、app/Models/ の下のファイルに書かれたメソッド（フレームワークのトレイトから入るメソッドを除く）のうち、戻り値の型宣言または PHPDoc が無いものを出す
models_missing() { tk 'foreach (["User","Genre","Book","Review","ReadingPlan"] as $m) { $c = new ReflectionClass("App\\Models\\".$m); foreach ($c->getMethods() as $f) { if ($f->getDeclaringClass()->getName() !== $c->getName()) continue; if (! str_contains((string) $f->getFileName(), "/app/Models/")) continue; if (! $f->hasReturnType()) echo "$m::{$f->getName()} no-return-type\n"; if ($f->getDocComment() === false) echo "$m::{$f->getName()} no-phpdoc\n"; } }'; }
```
