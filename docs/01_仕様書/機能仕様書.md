# BookShelf 機能仕様書

機能ごとの動き（入口・権限・入力ルールとエラー文言・成功時・失敗時）を載せる。画面・ルート・テーブルの一覧は全体仕様書（画面18枚・ルート52本・テーブル13個の一覧とテーブル定義）に、そう作った理由は技術決定書（学校の要件と実装が違う箇所とその理由）にある。

- 記述の基準: 現在の実装コード。記述と実装が食い違った場合は実装が正
- 出典の書き方: コードの位置は、名前空間を含むクラス名とメソッド名で示す（`App\Http\Controllers\BookController@index`）。Blade・設定ファイル・言語ファイルはリポジトリ内のパスと、その中のキー名で示す。行番号は使わない
- 画面ID（PG01〜PG18）とルート番号（No 001〜052）: 全体仕様書の画面一覧・ルート一覧が画面とルートに付けた通し番号。この文書の番号は同じものを指す

| 画面の入力エラー | 入力画面に戻り、入力値を残したまま各項目の下にエラー文言を表示（Laravel標準の動き） | 各 FormRequest |
| 権限の無い操作 | 403画面 | `App\Exceptions\Handler@register`（403の描画） |
| 存在しないURL・ID | 404画面 | `App\Exceptions\Handler@register`（404の描画） |
| CSRFトークンの不一致（画面を長く開いたまま送信したときを含む） | 419画面 | `App\Exceptions\Handler@register`（419の描画） |

| ヘッダー | 書籍一覧・ランキング・書籍登録・お気に入り・ジャンル管理・マイレポート・読書計画のリンクは未ログインでも表示（押すとログイン画面へ）。ログイン中は通知ベル（未読件数の赤丸）とユーザー名メニュー（ログアウト）、未ログインはログイン・新規登録を表示 | `resources/views/layouts/navigation.blade.php` |

### 1-3. 書籍登録（PG03）　No 012・011

| 項目 | 内容 | 出典 |
|---|---|---|

| 項目 | ルール | エラー文言 | 出典 |
|---|---|---|---|
| タイトル `title` | 必須・文字列・255文字以内 | 「タイトルを入力してください」「タイトルは255文字以内で入力してください」 | `App\Http\Requests\StoreBookRequest`・`App\Http\Requests\UpdateBookRequest` |

| ISBN `isbn` | 任意・文字列・数字13桁・未登録（削除済みの書籍のISBNとも重複不可） | 「ISBNは13桁の数字で入力してください（入力がある場合のみ）」「このISBNは既に登録されています」 | `App\Http\Requests\StoreBookRequest`・`App\Http\Requests\UpdateBookRequest` |

#### ISBNからの自動入力（登録画面のみ）　No 013

| 項目 | 内容 | 出典 |

| 画面の失敗表示 | 返ってきた `message` を赤字で表示（無ければ「書籍情報の取得に失敗しました」） | `resources/views/books/create.blade.php` |

## 2. ジャンル

対象ルート: No 022〜028。すべてログイン必須。ジャンルに所有者は無く、ログイン中の会員なら誰でも登録・編集・削除できる（`routes/web.php` の auth ミドルウェア内の `genres` ルート）。

| 画面・操作 | 内容 | 出典 |
|---|---|---|
| 一覧（PG05）`GET /genres` | 全ジャンルをID順に、ジャンル名・書籍数（「N冊」。削除済みの書籍は数えない）・編集／削除ボタンで表示。0件は「ジャンルが登録されていません。」 | `App\Http\Controllers\GenreController@index`、`resources/views/genres/index.blade.php` |
| 詳細（PG06）`GET /genres/{genre}` | そのジャンルの書籍（削除済みを除く）を新しい順に1ページ10件。0件は「このジャンルの書籍はまだ登録されていません。」 | `App\Http\Controllers\GenreController@show`、`resources/views/genres/show.blade.php` |
| 登録（PG07）`GET /genres/create` → `POST /genres` | 成功時はジャンル一覧へ「ジャンルを登録しました」 | `App\Http\Controllers\GenreController@create` と `@store` |
| 編集（PG08）`GET /genres/{genre}/edit` → `PUT・PATCH /genres/{genre}` | 成功時はジャンル一覧へ「ジャンルを更新しました」 | `App\Http\Controllers\GenreController@edit` と `@update` |
| 削除 `DELETE /genres/{genre}` | 紐づく書籍が1冊でもあれば（**削除済みの書籍を含む**）削除せず、ジャンル一覧へ赤い帯で「このジャンルに紐づく書籍が存在するため削除できません」。無ければ削除（物理削除）してジャンル一覧へ「ジャンルを削除しました」。DB側も紐付けがあれば削除を拒否する（二重の防御） | `App\Http\Controllers\GenreController@destroy`、`book_genre` テーブルの `genre_id`（`genres.id` を restrict で参照） |

入力ルール（登録・更新共通。更新では重複チェックから自分自身を除く）

| 項目 | ルール | エラー文言 | 出典 |
|---|---|---|---|
| ジャンル名 `name` | 必須・文字列・255文字以内・未登録 | 「ジャンル名を入力してください」「ジャンル名は255文字以内で入力してください」「このジャンル名は既に登録されています」 | `App\Http\Requests\StoreGenreRequest`、`App\Http\Requests\UpdateGenreRequest` |

一覧の書籍数は削除済みを数えない一方、削除の可否は削除済みも含めて判定する。そのため「0冊」と表示されていても削除できない場合がある。

## 3. レビュー・いいね

対象ルート: No 020・045〜048。すべてログイン必須。

| 操作 | 内容 | 出典 |
|---|---|---|
| 投稿 `POST /books/{book}/reviews` | 書籍詳細の投稿フォームから送る。同じ会員が同じ書籍に何件でも投稿できる（一意の制約なし）。成功時は書籍詳細へ「レビューを投稿しました」。削除済みの書籍には投稿できない（404） | `App\Http\Controllers\ReviewController@store`、`routes/web.php` の `POST /books/{book}/reviews` |
| 編集（PG09）`GET /reviews/{review}/edit` → `PUT /reviews/{review}` | 投稿者本人のみ（本人以外は403）。書籍が削除済みでも編集できる。成功時は書籍詳細へ「レビューを更新しました」 | `App\Http\Controllers\ReviewController@edit` と `@update`、`App\Policies\ReviewPolicy@update`、`App\Models\Review::book`（削除済みの書籍も取れる関連） |
| 削除 `DELETE /reviews/{review}` | 投稿者本人のみ。物理削除し、そのレビューへのいいねも連動して消える。書籍が削除済みでも削除できる。成功時は書籍詳細へ「レビューを削除しました」。確認ダイアログ「本当に削除しますか？」 | `App\Http\Controllers\ReviewController@destroy`、`review_likes` テーブルの `review_id`（`reviews.id` を cascade で参照） |
| いいね `POST /reviews/{review}/like` | 押すたびに登録・解除を切り替える。自分のレビューにも押せる。書籍が削除済みのレビューにも押せる。元の画面に戻り、メッセージは出さない。ボタンは「いいね (件数)」／「いいね済み (件数)」 | `App\Http\Controllers\ReviewController@like`、`resources/views/books/show.blade.php` |

入力ルール（投稿・更新共通）

| 項目 | ルール | エラー文言 | 出典 |
|---|---|---|---|
| 評価 `rating` | 必須・整数・1〜5。画面では「選択してください」＋★1〜★5のプルダウン | 「評価を選択してください」「評価は1〜5の範囲で選択してください」 | `App\Http\Requests\StoreReviewRequest`・`App\Http\Requests\UpdateReviewRequest` |
| コメント `comment` | 任意・文字列・1000文字以内。placeholder「この書籍の感想を書いてください」 | 「コメントは1000文字以内で入力してください」 | `App\Http\Requests\StoreReviewRequest`・`App\Http\Requests\UpdateReviewRequest` |
